01

核心概念

短期反转 & 中长期动量

🔄 什么是短期反转？

一句话：过去 1 个月跌多了的资产，未来容易反弹
  • 原因：噪声交易者（散户、杠杆投机者）让价格暂时偏离基本面
  • 做市商承接这些"噪声订单"需要补偿 → 价格过度反应
  • 过度反应之后 → 价格回归均值
论文证据：表2 显示 ρ₁ < 0（过去1个月收益与未来收益负相关）
📉 → 📈
短期跌多了 → 反弹
BTC 散户参与度高 + 杠杆放大
→ 反转效应比股票更强

🚀 什么是中长期动量？

一句话：过去 3-12 个月涨的资产，未来可能继续涨
  • 原因：信息反应不足 — 投资者对非自己产生的信息不够重视
  • 新信息（如 ETF 获批、减半周期）→ 价格逐步消化，而不是一步到位
  • 这个"消化过程"就形成了趋势延续
论文证据：表2 显示 ρ₃…ρ₁₂ > 0（滞后3-12月收益与未来收益正相关）
📈 → 📈📈
中长期涨 → 继续涨
关键技巧："跳过"最近 1 个月
消除反转干扰 → 动量更纯粹

🤝 反转 vs 动量 — 如何共存？

看似矛盾：一个说"跌了要涨"，一个说"涨了还涨"？

🔄 短期反转
时间窗口：1 个月
驱动因子：噪声交易（散户投机）
逻辑：价格偏离 → 回归
🚀 中长期动量
时间窗口：3-12 个月
驱动因子：信息反应不足
逻辑：信息消化 → 趋势延续
💡 JLST 的核心洞察：两者不矛盾！它们的驱动因子不同、时间尺度不同。 噪声交易越多 → 反转越强 + 动量越弱。这个跷跷板关系在 39 个国家都成立。

📢 噪声交易者 = 关键变量

论文核心发现（命题1）：噪声交易规模 ↑ → 反转增强 & 动量减弱

什么是噪声交易者？

  • 不基于基本面分析、而是跟风/情绪驱动的交易者
  • 散户 FOMO 追涨、恐慌杀跌
  • 高杠杆投机者
  • 他们让市场短期过度反应

BTC vs 股票

股票BTC
散户占比约 20%>60%
最大杠杆2-4x125x
交易时间6.5h/天24/7
预期反转强度一般更强

📐 公式一图流

Composite = wRev × Revz + wMom × Momz
  • Revz = 短期反转因子（z-score 标准化）
    过去 30 天的对数收益率
  • Momz = 中长期动量因子（z-score 标准化）
    过去 270 天收益，跳过最近 21 天
  • wRev, wMom = 动态权重
    由噪声代理自动调节，和为 1
动态权重调节：
🔊 噪声高时（市场投机热）
→ wRev ↑  wMom ↓
🔇 噪声低时（市场理性）
→ wRev ↓  wMom ↑
综合评分 > 0 → 看多
综合评分 < 0 → 看空

⚡ 级联预警

智能过滤机制

  • 死区过滤（±0.25）
    评分在 −0.25 到 +0.25 之间时不发信号，避免噪声
  • 信息冲击衰减
    BTC 突然暴涨/暴跌后 10 天内，反转权重打 0.4 折
  • 反转-动量相关性惩罚
    当 corr(Rev, Mom) > 0.20 时，评分打 0.6 折（机制异常）
  • 减半周期增强
    减半后 540 天内动量信号增强 1.2 倍

参数 v1（论文原版） v2（BTC 适配） 含义

v2 的改进：① 入场阈值降低 → 捕获更多有效信号 ② 动量窗口缩短 → 适应 BTC 更快的信息传播 ③ 加入资金费率 → 更直接衡量杠杆投机热度

v2 参数通过 2017-2023 年 BTC 日线数据网格搜索优化，2024-2026 年数据样本外验证

💰 为什么资金费率很重要？

什么是资金费率 (Funding Rate)？
永续合约多空双方之间每 8 小时支付一次的费用
  • FR > 0（正）：多头付费给空头
    → 市场做多过度，杠杆/投机热度高
  • FR < 0（负）：空头付费给多头
    → 市场做空过度
  • FR 绝对值越大 → 噪声交易越活跃
v2 噪声代理公式：
noise_z = 0.25×ATR + 0.25×量比
+ 0.20×机制 + 0.30×|FR|_z
论文用"机构持仓比"衡量噪声
BTC 没有这个数据
→ 资金费率是最好的替代品
它直接反映了市场的杠杆投机程度

使用场景

什么时候用？怎么用？

✅ 适合的场景

  • 🧭 方向性过滤器
    综合评分 > 0 → 偏向做多方向
    综合评分 < 0 → 偏向做空方向
    作为你现有策略的"第二意见"
  • 📏 仓位管理辅助
    评分绝对值越大 → 信号越强 → 可以考虑加大仓位
    评分在死区 → 轻仓/观望
  • 📡 噪声/投机热度监控
    noise_z 高 + 资金费率极端 → 市场投机过度
    当心短期反转（回调）
  • 📅 日线/周线级别决策
    不是日内交易工具，适合 1-30 天的持仓周期

❌ 不适合的场景

  • 🚫 单独当交易系统
    这是指标，不是策略
    不包含止损、仓位管理、风控
  • 🚫 短线/高频交易
    基于日线数据，不适合分钟级操作
  • 🚫 忽略风险管理
    任何单一指标都不应该是你交易的唯一依据
  • 🚫 "包赚不赔"的幻想
    胜率约 57%，近一半时候是错的
    必须配合风控才有意义

🖥️ 仪表盘怎么用？

Step 1：每日检查综合评分
打开 仪表盘 → 看"综合评分"卡片 → 绿色 = 看多偏向 / 红色 = 看空偏向
Step 2：关注信号出现
K 线图上出现 ▲ 或 ▼ 标记 → 查看信号历史表 → 确认信号类型和评分强度
Step 3：结合其他指标确认
JLST 做多 + 你的其他指标也看多 → 增加做多信心
JLST 做多 + 其他指标看空 → 谨慎，可能不做或减仓
Step 4：监控特殊状态
⚠️ 相关性转正（corr > 0.20）→ 机制异常，信号可靠性下降
⚡ 信息冲击窗口 → 暂时不要依赖反转逻辑
📡 噪声极高 → 当心短期剧烈回调

局限性 & 总结

必读 ⚠️

⚠️ 局限性（必读）

  • 📊 横截面 ≠ 时间序列
    论文研究的是"不同股票之间的对比"，我们是"单个 BTC 的时间序列"——统计意义不完全等价。请作为方向性参考，不是绝对真理。
  • 📉 过拟合风险
    v2 参数通过历史数据优化，存在对训练期过拟合的可能。测试期 7D Sharpe 仅 0.01（接近随机），说明样本外衰减明显。
  • 📅 样本量短
    仅约 9 年可靠 BTC 数据，市场结构已多次变化（纯散户 → 期货 → 机构 ETF）。所有统计估计都有较宽的置信区间。
  • 🔧 不含风险管理
    这是一个指标/过滤器，不是完整的交易系统。没有止损、仓位管理、最大回撤控制。
  • 🧊 减半模块是叙事性的
    历史上仅 4 次减半事件，且与宏观事件混淆。减半增强逻辑仅作视觉参考。

📝 总结

核心要点

  • 反转 + 动量 = 统一框架
    JLST 用噪声交易理论解释了两者如何共存
  • 噪声交易是核心变量
    BTC 散户/杠杆主导 → 反转效应比股票更强
  • v2 适配 BTC 市场结构
    资金费率 + 回测优化 → 信号质量提升
  • 做多信号 > 做空信号
    Long 7D: +3.25%(61%) vs Short: +0.76%(51%)
  • 用作辅助工具，不是圣杯
    胜率 ~57%，必须结合风控和其他指标
